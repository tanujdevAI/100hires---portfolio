## What I Figured Out (And How)

### Step 1 — Understanding GitHub
I had no idea what GitHub was. I used Google and Claude AI to understand it.
I learned that GitHub is like Google Drive for code — a place where developers 
store, share, and collaborate on projects publicly. Once I understood the concept, 
I signed up, named my profile "tanujdevAI" and explored the platform.

I also learned the difference between public and private repositories, what 
a README.md file is and why developers use it, and how code can be shared 
and reviewed by anyone in the world through GitHub.

### Step 2 — Creating the Repository
I found the "+" icon on the top right corner of GitHub and created a new 
public repository named "100hires---portfolio". I figured out what each setting 
meant (public vs private, README toggle) before clicking Create.

### Step 3 — Installing Cursor IDE
Downloaded Cursor from cursor.com and installed it like a regular application.
When I first opened it, it showed an AI agent panel — not the code editor 
I expected. I realized this was a different view and used Google + Claude to 
figure out that I needed to open the actual editor window where code is written.

### Step 4 — Finding Extensions (The Tricky Part)
This was my biggest challenge. The Extensions option was not where I expected 
it to be. The keyboard shortcut Ctrl+Shift+X was not responding in the AI panel.

I solved this by switching to the main editor window in Cursor by clicking on file < Open Editor Window — the area where 
actual code is written and terminals are opened. From there, I found the 
Extensions icon in the left sidebar and it worked immediately.

### Step 5 — Installing Claude Code
Searched "Claude Code" in the Extensions marketplace. I noticed there were 
many results from different developers. I specifically chose the one published 
by **Anthropic** — the official company — because I understood that using 
the original source matters. Installed and logged in successfully.

### Step 6 — Installing Codex
Searched "Codex" and installed **Codex – OpenAI's coding agent** published 
by **openai** — again choosing the official publisher. Successfully installed.

## Tools Installed and What I Learned About These Tools

**GitHub** — A platform for hosting and sharing code. Developers use it to 
collaborate, track changes, and show their work to potential employers. 
I now understand why every developer has a GitHub profile.

**Cursor IDE** — A code editor with AI built directly into it. It has two 
modes: an AI agent panel for planning, and an editor window for writing code. 
The extensions make it even more powerful.

**Claude Code** — An AI assistant by Anthropic that helps developers write, 
debug, and improve code directly inside the editor.

**Codex by OpenAI** — Another AI coding agent by OpenAI that works alongside 
you while you write code, offering suggestions and automations.
